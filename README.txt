# Richa — Full-Screen Page-Turn Proposal

The site is now a full-screen, section-by-section experience instead of a vertical scroll page.

## Navigation
- Every section fills the entire viewport.
- Each section has a "next" button.
- Clicking next performs a 3D book-page turning animation.
- The next section takes over the full screen.
- Keyboard: Right Arrow / Enter / Space = next; Left Arrow = previous.
- Mobile: swipe left/right to navigate.
- Page indicator appears in the top-right.

## Files
- index.html
- style.css
- script.js

## Photo
Replace the dummy Unsplash URL inside `.photo-frame` in `index.html`.

## Music
No autoplay music is included. To add your own romantic instrumental, use a local/licensed audio file and start it after a user interaction to avoid browser autoplay restrictions.

## No framework
Only HTML, CSS, JavaScript and jQuery are used.
